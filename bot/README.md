# Бот меток для Twitch

Бот сидит в чате твоего канала и по команде **`!clip`** / **`!клип`** / **`!метка`**
записывает «метку момента»: время, кто написал (стример / модер / вип / зритель) и
заметку. Потом приложение превращает эти метки в вертикальные клипы.

> **Главное:** бот встроен в приложение. Ставить Python, добывать токены и править
> файлы настроек **не нужно**.

---

## Как включить (30 секунд)

1. Открой «Полировщик клипов» → бургер-меню → режим **«Метки через бота»**.
2. Справа вверху вкладка **«Бот»**.
3. Нажми **«Войти через Twitch»**. Откроется страница Twitch с полем для кода —
   приложение покажет этот код (например `WHFYNRWP`), его надо подтвердить.
   Пароль приложение не видит: вход целиком на стороне Twitch. Права запрашиваются
   только на чтение и отправку сообщений в чат.
4. Канал подставится сам (твой). Жми **«Подключить бота»**.

Бот в чате. Точка. Отдельный аккаунт для бота не нужен — он пишет от твоего ника.

## Автопилот (по умолчанию включён)

С автопилотом бота вообще не надо включать руками: он сам заходит в чат, когда начинается
эфир, и выходит, когда эфир закончился. Единственное условие — программа должна быть
запущена. Для этого во вкладке «Бот» есть две галочки:

- **«Запускать вместе с Windows»** — программа стартует свёрнутой в трей (значок у часов).
- **«Закрытие окна сворачивает в трей»** — крестик не убивает бота, он продолжает работать.
  Открыть обратно — двойной клик по значку у часов, выйти совсем — правый клик → «Выход».

Хочешь всё руками — выключи автопилот, тогда кнопка «Подключить бота» работает как раньше
(бот сидит в чате даже без эфира, удобно для проверки).

## Один эфир — один файл (ничего не смешивается)

Каждый эфир пишется в свой файл: `<канал>_<дата>_<время>_<id эфира>.clipmarks`. Два стрима
за день не мешают друг другу, а в приложении видно, что за эфир: «Эфир 26 июля, 21:04 ·
«Название стрима» · 2 ч 15 мин · 12 меток». Название и дата эфира попадают и в имена клипов.

Время метки считается от **старта эфира**, поэтому метки сразу совпадают с записью OBS.
Если бот работал до эфира, те метки уйдут в отдельный файл «вне эфира». Если программу
перезапустить посреди стрима, она допишет тот же файл, а не начнёт его заново.

## Как пользоваться на стриме

1. Перед эфиром (или в любой момент) включи бота во вкладке «Бот».
2. Ты, модеры и зрители пишете в чат `!clip` — можно с текстом:
   `!clip рофл про кота` (текст станет названием момента).
3. Веди запись стрима в OBS/Twitch — нужна сама видеозапись.
4. После стрима: **«Взять эти метки в нарезку»** → выбери файл записи слева →
   приложение соберёт моменты → «Нарезать клипы».

Если запись началась позже эфира — включи слева **«Запись неполная»** и укажи сдвиг,
метки сами встанут на место. Когда идёт эфир, бот сам берёт за «ноль времени» его
старт, так что чаще всего сдвиг не нужен.

### Настройки во вкладке «Бот»
- **Метить могут** — все зрители или только стример с модерами.
- **Пауза для зрителя** (по умолчанию 30 с) — чтобы один человек не засыпал чат метками.
- **Подтверждать метку сообщением в чат** — бот отвечает «метка записана».

### Где лежат метки
`%LOCALAPPDATA%\ClipPolisher\marks\<канал>_<дата>_<время>_<id эфира>.clipmarks` — кнопка «Папка с метками»
открывает эту папку. Файл дописывается после каждой метки, поэтому ничего не теряется,
даже если программа закроется. Взять метки можно и позже — кнопкой «Импортировать файл
меток» слева.

## Проверить без эфира

Чат канала работает, даже когда ты **не** в эфире. Включи бота, открой свой чат
(`https://twitch.tv/popout/ТВОЙ_КАНАЛ/chat`) и напиши `!clip проверка` пару раз в
разные моменты — метки появятся в списке.

Онлайн вне эфира = 0, поэтому режим отбора «Авто» посчитает канал камерным и возьмёт
каждую метку. На реальном стриме онлайн подтянется сам.

## Частые вопросы

- **«Twitch не пустил в чат — нужно войти заново»** — вход протух или его отозвали.
  Нажми «Войти через Twitch» ещё раз.
- **Метки не пишутся** — проверь, что в поле «Канал» твой канал, а команда ровно
  `!clip` / `!клип` / `!метка` (регистр не важен).
- **Зрителю не даёт метить часто** — это пауза для зрителя, подними или обнули её.
- **Бот отвалился на секунду** — при обрыве связи он переподключается сам, метки
  из чата в этот момент могут пропасть; повтори команду.

## Запуск без окна (для продвинутых)

Бот умеет работать и из командной строки — например, на другом компьютере:

```
python bot/twitch_marks_bot.py --login     # войти через Twitch (покажет код)
python bot/twitch_marks_bot.py             # запуск на своём канале
python bot/twitch_marks_bot.py --autopilot # ждать эфира и зайти в чат самому
python bot/twitch_marks_bot.py --channel имя_канала
python bot/twitch_marks_bot.py --simulate  # без Twitch: печатать сообщения руками
python bot/twitch_marks_bot.py --logout    # забыть вход
```

Старый способ со своим токеном тоже работает: заполни `bot/config.json`
(`channel`, `bot_username`, `bot_oauth`) — тогда вход через Twitch не потребуется.
`config.json` и папка `marks/` в git не попадают.

Движок бота — `core/chatbot.py`, вход — `core/twitch_auth.py`; `bot/*.py` — только
обёртки для консоли.
